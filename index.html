About This Project
This project is a Data Structures and Algorithms (DSA) Visualizer that helps users understand complex algorithms through interactive animations. The main goal of this project is to make learning DSA easier and more intuitive by showing step-by-step visual execution instead of just code.
Features
  1. Visualize sorting algorithms
  2. Step-by-step execution
  3. Clean and interactive UI
  4. Single Page Application (SPA) with routing
  5. Theme switching (Dark/Light mode)
Technologies Used
  • HTML
  • CSS
  • JavaScript (Vanilla JS)
  • CDN for Font Awesome 6.5.1 and Google Fonts.
  • Hash-based Routing
